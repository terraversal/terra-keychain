# Terra Keychain
<!-- Provide a 1-2 sentence high-level overview of what the project does and its core value proposition. -->
Terra Keychain is a typing test for beginner and advanced speed-typers. It is a mix of premade typing tests and custom typing tests you can make yourself with one click.

- **Free, No Signup:** The app is completely free and no account, installation, or payments are required

- **Free, No Signup:** The app is completely free and no account, installation, or payments are required
- **Simplicity** The results of each test is consistent and direct, showing which keys each user has problems with, the WPM, and accuracy.
- **Sharing** You can share each typing test
