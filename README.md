# Terra Keychain

Terra Keychain is a typing test for beginner and advanced speed-typers. It is a mix of premade typing tests and custom typing tests users can make themselves with one click.

## Features

- **Free, No Signup:** The app is completely free and no account, installation, or payments are required.
- **Templates:** Instead of users making their own everytime, there are premade templates they can choose from which focus on keys that people commonly have trouble with.
- **Abstraction:** If a user prefers to not use special characters in the templates, clicking the abstraction checkbox removes those special characters entirely, and allows the typing test to not contain capital characters, leaving only lowercase letters from a-z.

## Roadmap

- [ ] **Showing the WPM and Accuracy:** The results will show the WPM and overall accuracy, along with keys each user has trouble on.
- [ ] **Abstraction for Custom Tests:** Each user will be able to abstract custom tests.
- [ ] **Template Generator:** A user can type specific problem keys and a paragraph will be generated automatically with AI.
